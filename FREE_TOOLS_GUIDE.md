# Free Tools Guide for QueueForge Growth

## Marketing Tools (Free)

### 1. Canva (canva.com)
**Use for:**
- QR code posters for shops
- Social media posts (Instagram, Facebook)
- WhatsApp status images
- Business cards
- Flyers for local distribution

**How to use:**
1. Sign up free at canva.com
2. Search "QR code menu" or "business card" templates
3. Customize with QueueForge branding
4. Download and print

### 2. Figma (figma.com)
**Use for:**
- Design new features
- Create wireframes
- Share with team
- Client presentations

**How to use:**
1. Sign up free at figma.com
2. Create a new design file
3. Use templates for mobile app mockups
4. Share link with developers

### 3. Leonardo AI (leonardo.ai)
**Use for:**
- Generate hero images
- Create icons
- Make social media graphics
- Product mockups

**How to use:**
1. Sign up free at leonardo.ai
2. Get 150 free tokens daily
3. Generate images with prompts like "modern barbershop queue management app"
4. Download and use

## Development Tools (Free)

### 4. v0.dev (v0.dev)
**Use for:**
- Generate React components
- Create UI elements
- Build dashboards

**How to use:**
1. Go to v0.dev
2. Describe what you want: "booking calendar component"
3. Copy the generated code
4. Paste into your project

### 5. Cursor (cursor.com)
**Use for:**
- AI-assisted coding
- Code completion
- Bug fixes

**How to use:**
1. Download Cursor (free tier)
2. Open your project
3. Use AI to generate/fix code
4. 2000 free completions/month

### 6. ChatGPT / Claude

- Plan features

**How to use:**
1. Go to chatgpt.com or claude.ai
2. Describe your problem
3. Get code solutions
4. Copy and implement

## How to Use These Tools Today

### Step 1: Create Marketing Materials (Canva)
1. Open Canva
2. Search "QR code poster"
3. Add QueueForge logo + QR code
4. Print 10 copies
5. Visit 10 barbershops

### Step 2: Create Social Media Content (Canva + Leonardo)
1. Generate 5 images with Leonardo AI
2. Create posts in Canva
3. Schedule with Buffer
4. Post daily for a week

### Step 3: Improve the App (v0.dev + Cursor)
1. Use v0.dev to generate better components
2. Use Cursor to fix bugs
3. Deploy to Vercel

### Step 4: Track Progress (Notion)
1. Create a Notion page
2. Track: shops visited, signups, revenue
3. Review weekly
